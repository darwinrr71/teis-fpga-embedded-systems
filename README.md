# TEIS – FPGA och inbyggda system

Tekniska rapporter från utbildningsuppgifter inom tillämpad elektronik och inbyggda system (TEIS / AGSTU).

Arkivet innehåller **26 PDF-rapporter**, organiserade efter utbildningsområde och uppgift. Dokumenten är mina tekniska rapporter och beskriver bland annat konstruktion, genomförande, analys och resultat inom VHDL, C, FPGA och hårdvarunära systemutveckling.

**Avgränsning:** Detta är ett dokumentationsarkiv, inte fullständiga byggbara projekt. Källkod, kompileringsfiler, uppgiftsbeskrivningar från AGSTU och kursmaterial från andra författare ingår inte.

Rapporterna har enbart redigerats för att permanent ta bort e-postadresser och deras klickbara länkar. Övrigt innehåll har bevarats. Identiska kopior av samma rapport har inte tagits med.
